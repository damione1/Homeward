# Product vocabulary

- **Home:** the selected server document’s overview.
- **Room:** a configured group of equipment and observations.
- **Details:** the dedicated controls for one exact equipment identity.
- **Shopping List:** the configured checklist used while shopping.
- **Lists:** the full list editor, selected through the native navigation.
- **Common Items:** items already present in the selected server list, including completed items that can be added again with the same identity.
- **Waiting for confirmation:** a command acknowledged without its authoritative observed result yet.
- **Unavailable:** the required source or capability is absent; this differs from a successfully loaded empty list.
